// =========================================
// PLC 课程作业 - 8个小灯与断码屏控制程序
// 编程语言：梯形图 (转换成指令表格式)
// =========================================

// 假设变量定义：
// MW10 = 输入的数字 (来自触摸屏或HMI输入)
// Q0.0 ~ Q0.7 = 8个小灯
// Q1.0 ~ Q1.6 = 断码屏的 a~g 段

// --- 第1个小灯 ---
LD  MW10
==I 1
=   Q0.0  // 第1个小灯亮

// --- 第2个小灯 ---
LD  MW10
==I 2
=   Q0.1  // 第2个小灯亮

// --- 第3个小灯 ---
LD  MW10
==I 3
=   Q0.2  // 第3个小灯亮

// --- 第4个小灯 ---
LD  MW10
==I 4
=   Q0.3  // 第4个小灯亮

// --- 第5个小灯 ---
LD  MW10
==I 5
=   Q0.4  // 第5个小灯亮

// --- 第6个小灯 ---
LD  MW10
==I 6
=   Q0.5  // 第6个小灯亮

// --- 第7个小灯 ---
LD  MW10
==I 7
=   Q0.6  // 第7个小灯亮

// --- 第8个小灯 ---
LD  MW10
==I 8
=   Q0.7  // 第8个小灯亮

// --- 断码屏显示部分 (简单演示显示数字1) ---
// 如果输入数字是 1，让b段和c段亮 (数字1的形状)
LD  MW10
==I 1
=   Q1.1  // b段
=   Q1.2  // c段

// (其他数字的断码显示逻辑类似，由于篇幅原因不全部列出)
